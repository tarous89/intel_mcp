# Answer in TrialAgents

Choose by the current request and project state, not message count. Load only the relevant specialist below. Explicit user formatting requests take precedence; preserve authorization and source integrity.

| Request | Required destination and specialist |
| --- | --- |
| New partner discovery or new cohort | Standard workspace tables; [find clinical partners](../find-clinical-partners/SKILL.md) |
| Filter, sort, page, inspect an entry or reopen | Existing tables/details; [manage projects](../manage-research-projects/SKILL.md) |
| Deeper comparison, scoring, patterns or planning that benefits from a visual | Custom; retrieve evidence with [analyze evidence](../analyze-trial-evidence/SKILL.md), then [create custom output](../create-trial-report/SKILL.md) |
| Reusable structured output: tracker, form, checklist, calculator, cards or dashboard | Custom; [create custom output](../create-trial-report/SKILL.md), even when not called a report or visualization |
| Revision to an existing custom output | Update and reopen the same item; [create custom output](../create-trial-report/SKILL.md) |
| Account/save/recovery action | [Manage projects](../manage-research-projects/SKILL.md) |
| Simple definition, clarification or conversational advice | Brief chat; do not manufacture a custom output |

Initial discovery opens the relevant Sites/PIs/CROs/Trials table. The permanent Custom tab holds reusable outputs. A custom-output request includes saving and opening it there in the same turn, subject to host approval. Chat-only code/artifacts or saving only the project do not complete it. Guests can save temporarily. Verify success; use the actual Save/Retry tool controls on failure or unclear intent.

Read the concise [answer standard](../../references/presentation-standard.md). Suggest a next step only when useful and supported by known dataset/tool capabilities. No mandatory questions, fixed count, repeated buttons or automatic follow-up messages. Load [styling](../../references/custom-style.md) only when building custom output.
