# 0.7.23 immediate save recovery — 18 October 2026

The owner authorized implementation and repository publication of one or two immediate retries for projects and Custom views, followed by a concise top notice and manual save control. This supersedes the proposed delayed second retry: no timer, polling, background scheduler or deferred optimization is included.

## Behavior

- At most two immediate retries are shared across the storage steps of one tool call, including nested preview preparation and project saving. Reuse the exact capability, snapshot, payload, request key and revision guard. Retry only transient HTTP failures (408, 500, 502, 503, 504); do not retry authentication, validation, conflicts, expiry, rate limiting or cancellation.
- Retry the failed step only. A lost verification response retries the read, not an already acknowledged write. A completed preview recovery can verify existing storage without another upload. Backend ownership, transaction/idempotency receipts and version checks remain authoritative.
- Exhausted publication returns the retained tables/draft and the correct connected save recovery. Direct project saves retain exact retry arguments. Failed Custom views retain their existing retry IDs/content. Instructions stop additional model retry loops after automatic_retry_complete=true, while honoring user-requested retry and corrected saves.
- One top notice and manual action remain after failure. Confirmed temporary previews use their returned lifetime (seven days for fresh storage); an interrupted cache write uses session-only wording, and an unverified Custom view does not claim temporary persistence. Existing project revisions are described as unsaved changes.
- Manual recovery preserves the active table/page and ignores responses superseded by a new tool operation, project or mutation. Concurrent table reads retain confirmed saved status. An explicitly saved cohort revision shows its new rows, not the former cohort under a new revision. The notice reserves vertical space to keep the footer reachable.
- All 38 tool names, input/output schemas and annotations are unchanged. Server descriptions, initial instructions, relevant skills, runtime mirrors and the review workflow are synchronized. Version 0.7.23 carries forward 0.7.22's Data & Analytics listing and all existing prompts/branding.
